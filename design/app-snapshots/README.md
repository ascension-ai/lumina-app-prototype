# Lumina Product Snapshot Studio

Open `index.html` in a browser or serve this folder with any static web server.

## Controls

- The studio automatically advances every seven seconds.
- Use the scene tabs or left/right arrow keys to navigate.
- Press Space or use the Pause button to stop autoplay.
- Clean view hides the studio controls for presentations and captures.
- Fullscreen provides a distraction-free demo.

## Direct scene links

- `index.html?scene=1` — Morning brief
- `index.html?scene=2` — Workflow compiler
- `index.html?scene=3` — Commitment tracker
- `index.html?scene=4` — Ambient answers

Adding a `scene` query parameter opens the selected scene paused, which makes consistent screenshots easier.

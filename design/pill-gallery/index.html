Sleeping state — what lives on the screen 95% of the time

Reality check for Electron. The window is transparent: true with hasShadow: false, so CSS backdrop-filter will not blur the desktop behind it — every fill here is opaque or near-opaque by design. If you want genuine frosted glass, that is a main-process change (vibrancy: 'hud' on macOS), not a CSS one. Growth is anchored to the bottom edge because resize-floating keeps bottom = y + height fixed — all five prototypes grow upward for that reason.

Concepts B and C need a main-process tweak: B wants a ~4px sleeping window instead of the current 56px one (the sleeping seam is thinner than today's sliver), and C wants y = screenH - height with no 20px gap so the notch fuses to the screen edge.
